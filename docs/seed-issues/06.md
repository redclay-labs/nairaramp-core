# Add SEP-12 KYC status helper `ramp.getKycStatus()`

### Context
In `docs/anchors-nigeria.md`, research verified that Cowrie (`cowrie.exchange`) operates a live SEP-12 KYC server (`https://api.cowrie.exchange/kyc`) and requires customer identification (`customer_id`) before initiating deposits or withdrawals. The SDK currently manages SEP-10 authentication and SEP-24 hosted URLs, but provides no convenience method for querying a user's SEP-12 verification status (`GET /customer`).

### Done when
- [ ] Add `getKycStatus(options?: { type?: string }): Promise<KycStatusResponse>` to `Ramp` interface in `src/ramp.ts`.
- [ ] Implement `getKycStatus` using Wallet SDK `sep12` client with the authenticated SEP-10 JWT.
- [ ] Return parsed status (e.g., `"ACCEPTED"`, `"PROCESSING"`, `"NEEDS_INFO"`).
- [ ] Throw `NairaRampError("ANCHOR_NOT_FOUND")` or `NairaRampError("UNSUPPORTED_ASSET")` if the anchor does not advertise SEP-12.
- [ ] Map 401/403 responses to `AUTH_FAILED` and connection errors to `ANCHOR_UNREACHABLE`.
- [ ] Add unit tests with mocks in `test/ramp.test.ts` covering status return and error mapping.
- [ ] Export `KycStatusResponse` in `src/index.ts` and document in `docs/API.md`.
