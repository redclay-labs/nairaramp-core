# Implement SEP-38 firm quote request (`ramp.requestQuote`)

### Context
In `src/quotes.ts`, `ramp.getPrice()` currently provides indicative pricing using the SEP-38 `GET /price` endpoint. For anchors supporting firm quotes (`POST /quote`), users can lock in a guaranteed exchange rate for a designated expiration duration before executing a swap or transfer.

### Done when
- [ ] Define `RequestQuoteOptions` (`sellAsset`, `buyAsset`, `sellAmount?`, `buyAmount?`, `context?`, `expireAfter?`) and `FirmQuote` (`id`, `expiresAt`, `price`, `sellAsset`, `buyAsset`, `sellAmount`, `buyAmount`, `totalFee`, `feeAsset`).
- [ ] Add `requestQuote(options: RequestQuoteOptions): Promise<FirmQuote>` to `Ramp` in `src/ramp.ts` and `src/quotes.ts`.
- [ ] Authenticate via SEP-10 and call the Wallet SDK SEP-38 quote request method (`anchorClient.sep38(token).requestQuote(...)`).
- [ ] Throw `NairaRampError("QUOTE_UNAVAILABLE")` if the anchor does not support `POST /quote` or rejects the pair.
- [ ] Add unit tests with mocks in `test/quotes.test.ts` covering success, validation, and error mappings.
- [ ] Re-export types in `src/index.ts` and document in `docs/API.md`.
