# Promote verified Nigerian mainnet draft anchors to active registry

### Context
In Step 16 research (`docs/anchors-nigeria.md`), `ngnc` (`ngnc.online`) and `cowrie` (`cowrie.exchange`) were verified via Horizon mainnet and advertised SEP endpoints, and valid draft schemas were created in `src/registry/drafts/`. Currently, `src/registry/index.ts` strictly imports only `sdf-testanchor` to isolate mainnet anchors while under review. Once reviewed, verified mainnet drafts can be promoted to `src/registry/anchors/` and registered for production consumers.
