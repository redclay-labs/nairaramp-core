# Surface detailed Horizon result codes in `completeWithdrawal` transaction failures

### Context
In `src/ramp.ts` (lines 580–610), `completeWithdrawal(id)` builds and submits a payment transaction to Horizon to fulfill a withdrawal. When Horizon rejects a transaction, the catch block maps the error to `NairaRampError("TRANSACTION_FAILED")`:
```typescript
throw new NairaRampError(
  "TRANSACTION_FAILED",
  `Horizon transaction submission failed: ${err instanceof Error ? err.message : String(err)}`,
  { cause: err }
);
```
Horizon rejection responses contain rich diagnostic details in `error.response?.data?.extras?.result_codes` (such as `transaction: "tx_failed"`, `operations: ["op_underfunded"]`). Extracting these operation codes directly into the error message significantly reduces debugging time for app developers.

- [ ] Add unit tests in `test/ramp.test.ts` mocking Horizon error response payloads and asserting that the error code string appears in `NairaRampError.message`.
