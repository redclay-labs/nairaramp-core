# Probe alternate subdomains for unverified Nigerian anchor candidates

### Context
In `docs/anchors-nigeria.md`, several anchors listed on `https://anchors.stellar.org` (`Yellow Card`, `Paychant`, `Busha`) were marked "could not verify" because root domains returned 404 or redirected to marketing landing pages without publishing `/.well-known/stellar.toml`. Many fintech anchors host their TOML files and SEP servers on dedicated infrastructure subdomains (for example, `api.yellowcard.io`, `stellar.paychant.com`, or `api.busha.co`).

### Done when
- [ ] Query Horizon assets for known Nigerian anchor asset codes (e.g. `cNGN`, `BUSD`, `USDC`) to identify issuer accounts and inspect their `home_domain`.
- [ ] Probe candidate subdomains (e.g., `api.`, `anchor.`, `stellar.`) for `/.well-known/stellar.toml` using `curl`.
- [ ] Record trimmed headers, HTTP status codes, and advertised SEP endpoints in `docs/anchors-nigeria.md`.
- [ ] If any candidate successfully answers with live endpoints, create a corresponding draft entry in `src/registry/drafts/`.
- [ ] Update verdicts and check dates in `docs/anchors-nigeria.md`.
