# Document integration test flags and Friendbot testnet workflow in `CONTRIBUTING.md`

### Context
`CONTRIBUTING.md` documents standard offline build commands (`pnpm test`, `pnpm build`, `pnpm lint`, `pnpm typecheck`), but omits instructions on how contributors can run live testnet integration tests (`pnpm test:integration`). Live tests (`test/integration/sep10.test.ts`, `sep24.test.ts`, `sep38.test.ts`, `withdraw.interactive.test.ts`) require setting `RUN_INTEGRATION=1` and `RUN_INTERACTIVE=1` and rely on Stellar Friendbot for testnet funding.
