# Implement SEP-6 non-interactive deposit flow (`ramp.depositSep6`)

### Context
In `docs/anchors-nigeria.md`, research verified that Cowrie Exchange (`cowrie.exchange`) supports SEP-6 (`TRANSFER_SERVER: https://api.cowrie.exchange/transfer`) for `NGNT`, but does not advertise `TRANSFER_SERVER_SEP0024`. Currently, `@nairaramp/core` only supports SEP-24 hosted deposits (`ramp.deposit`), preventing developers from initiating deposits with anchors that only offer SEP-6 APIs.

### Done when
- [ ] Define `Sep6DepositOptions` (`assetCode`, `account`, `amount?`, `memo?`, `type?`) and `Sep6DepositResponse` (`how`, `id`, `eta`, `min_amount`, `max_amount`, `fee_fixed`, `fee_percent`, `extra_info`).
- [ ] Implement `depositSep6(options: Sep6DepositOptions)` in `src/ramp.ts` using the Wallet SDK SEP-6 deposit method.
- [ ] Check that `anchor.seps.includes("sep6")` before making network calls, throwing `NairaRampError("UNSUPPORTED_ASSET")` or `NairaRampError("TRANSACTION_FAILED")` if missing.
- [ ] Handle SEP-12 KYC requirement responses, throwing `NairaRampError("KYC_REQUIRED")` with instructions.
- [ ] Add unit tests with mocks in `test/ramp.test.ts` covering success, missing sep6, KYC required, and network errors.
- [ ] Export types in `src/index.ts` and document in `docs/API.md`.
