# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@nairaramp/core`, please report it through GitHub private vulnerability reporting:

1. Navigate to the repository's **Security** tab.
2. Select **Advisories** and click **Report a vulnerability**.
3. Provide details and reproduction steps.

**Never report security vulnerabilities through public GitHub issues, pull requests, or public discussions.**

## Supported Versions

Only the latest `0.x` release receives security updates and bug fixes.
